## omarchy setup

- Checkout: `~/work/mhc` (fork `Momentum96/mhc`, branch `dori/compat-20261122`).
- Upstream clones: `~/work/upstream/senpi` and `~/work/upstream/oh-my-openagent` (full history and tags). The pinned
  senpi checkout is `~/work/upstream/senpi-pin`; every test run sets `SENPI_SRC=$HOME/work/upstream/senpi-pin`.
- Disks: `~/work` is on a slow HDD. Build output goes to the NVMe at `/mnt/nvme-work`: each checkout's or worktree's
  `target` is a symlink to `/mnt/nvme-work/targets/<name>` (roadmap.md rule 6).
- Cargo lock: several agents build at once, so every cargo command runs as
  `flock $HOME/work/.mhc-cargo.lock cargo ...`.
- Linux packaging needs the host glibc as the ceiling: `MHC_GLIBC_CEILING=2.44` on both the package and the
  `--verify-only` command (roadmap.md, "Repackage on omarchy").
- Claude consent: `providerRiskConsent.anthropic-subscription` is recorded only in the shadow HOME
  (`~/.maho/home/.omo/agent/settings.json`), never in the real `~/.omo`.
