# Persistent host policy and host session endpoint authentication

| TS path | Rust path | TS tests | Rust tests | status |
|---|---|---:|---:|---|

| rpc/rpc-client-socket.ts | src/rpc_client.rs | 0 | 1 | partial |

The pinned supervisor passes an infinite idle window to its idle decision for
`coldStart=persistent`; the configured duration still controls owner tick cadence.
The POSIX `host session` runner uses the existing mutual endpoint authentication
before transferring the connection to the command mux. The native named-pipe
session client is unchanged.
